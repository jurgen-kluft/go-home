# Environment Sensor

- Uses YD ESP32 S3
- Need small PCB that exposes I2C, UART and power connections.
  - I2C:
    - BH1750 (light)
    - BME280 (temperature, humidity, pressure)
    - SCD41 (CO2, temperature, humidity)
    - SH1107 (Display)
  - UART:
    - RD03D mmWave radar (presence detection)
