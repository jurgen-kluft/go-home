# Magic Cube

- Fire Beetle ESP32
- SC7A20H:
  - three-axis gravitational acceleration sensor
  - free-fall detection interrupt signals
  - sleep and wake-up detection interrupt signals
  - single-click and double-click detection interrupt signals
- Battery powered, USB-C charging

## Features

- 3D printed case
- USB-C charging
- 6 sides, each side triggers an event:
    - event 'side 1 up' when cube is idle and side 1 is up
    - event 'side 2 up' when cube is idle and side 2 is up
    - ...
- event 'side 1 tap' when cube is idle, side 1 is up, and the cube is tapped
- event 'side 2 tap' when cube is idle, side 2 is up, and the cube is tapped
- ...

## 3D Case

- 3D Cube, with inside:
  - Fire Beetle ESP32
  - 6 axis MPU6050
  - Battery
