# Button

This project is a button that is part of the latch circuit. It is designed to mainly be used as a button.

- ESP8266 microcontroller
- Latch circuit that is triggered by the button
- Battery powered, USB-C charging

## Features

- 3D printed case
  - Circular, 50 mm diameter, 20 mm height
- Physical button
- USB-C charging

## 3D Case

- 3D printed case, with inside:
  - ESP8266 microcontroller
  - Latch circuit
  - Button
  - Battery
