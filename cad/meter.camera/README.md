# Meter Camera

The Meter Camera is a small camera module designed for use with the ESP32-S3-CAM and OV3660 image sensor.
One of its main use cases is to capture images of a meter display, such as an electricity, gas or water meter, for remote monitoring and data collection.

It features a 3D printed case and USB-C charging capabilities.

- ESP32-S3-CAM
- OV3660

## Features

- 3D printed case
- USB-C charging

## 3D Case

- Enclosure, with inside:
  - ESP32-S3-CAM
  - OV3660
  - Battery
