# Meter Camera

The Meter Camera is a small camera module designed for use with the ESP32-S3-CAM and OV3660 image sensor.

One of its main use cases is to capture images of:

- a gas/water/electricity meter display
- mailbox (bottom has picture with the word EMPTY on it, no recognizable word means full)

for remote monitoring and data collection.

## Features

- 3D printed case
- Battery powered, with low power timer for periodic wake-up

## 3D Case

- 3D printed case, with inside:
  - ESP32-S3-CAM (GooUUU ESP32-S3-CAM)
  - OV3660
  - Battery, 32700 LiFePO4, 8000 mAh, 3.2V, 8.0Ah, 25.6Wh
  - TPL5110, Low Power Timer Breakout Board, 1.8V to 5.5V, 1.5uA, 100ms to 2 hours
